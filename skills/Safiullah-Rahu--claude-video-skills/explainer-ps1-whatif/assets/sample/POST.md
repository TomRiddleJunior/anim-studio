## Music note
The full mix carries an original bed synthesized in code (D-minor pad, a sparse bell line on a 72 BPM grid, tape wow),
matched to the source's measured bed (tonal, D minor, no steady pulse, about 14 dB under the voice). To use an in-app
library track instead, post `ps1-rewind_nomusic.mp4` and search the library for **"lofi ambient"**, **"retro game
ambient"** or **"dreamy synth"** around 70–80 BPM, in a minor key, without vocals; set it low (about −15 dB under the
voice) so the rewind whirrs and the VCR clunks stay audible.
