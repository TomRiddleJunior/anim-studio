# Storylines

**Picked — A. Earth OS: weekly patch notes** (recommended: the futuristic UI the request asks for becomes the joke itself, and a
stranger follows "six open tickets" easily).
Device: type carries the argument + the object is the explanation (the planet as an operating system). Form: a flight
through one world — the globe is home; each story is a dive to a hotspot and back.
First two seconds: a cloud of scattered dots snaps into a dotted globe while a boot line types
"EARTH OS 26.10 · weekly status"; the first red ping lights over the Strait of Hormuz.
Beats: boot → 6 tickets (Hormuz, Alaska, Israel, Brazil, Serbia, Venezuela), each = fly-to, dive onto NASA imagery,
ticket card + real headline screenshot as evidence + one deadpan status line → pull back to the orb, ticket board →
"next scheduled update: 3 Nov" end card.
Look: deep ocean-blue globe in NASA Blue Marble imagery and a dotted-land orb, ice-white UI with one signal-orange accent for
status chips; Space Grotesk / Inter / JetBrains Mono.
Sound: upbeat synth pulse at 120 bpm, energy up at each dive, a riser into the final board; whooshes on dives, a pop on each
status chip.

**B. The political weather forecast.** A TV-weather globe with storm systems spinning over hotspots ("80% chance of
recounts"), the presenter replaced by an animated pointer; real headlines appear as warning banners. Cut on the beat
between regional forecasts.

**C. The world's group chat.** The globe sits in the middle of a messaging app; each country "posts" its week as a real
headline screenshot, reactions and typing indicators pile up, and the chat scrolls to the next. One frame that keeps
rebuilding itself.
